# Color Picker App - React

A fun and interactive Color Picker application built with React. Allows users to select colors using both a native color picker and manual text input (with validation).

## ✨ Features

- **Native Color Picker** (`<input type="color">`)
- **Text Input Support** — Enter color names (e.g., `red`, `blue`) or HEX codes (e.g., `#FF0000`)
- Real-time color validation
- Live preview box that updates instantly
- Clean component-based architecture (`ColorPicker`, `TextInput`, `Box`)

## 🛠 Technologies Used

- **React.js** (Functional Components + Hooks)
- `useState` for state management
- JavaScript (ES6+)
- Inline styling (for demonstration)
